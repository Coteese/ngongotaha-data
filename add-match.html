Unlock

Paste your GitHub access token to add match results. The token is only ever stored on this device, never in the website code, so nobody else can use this page.

How to get a token (one-time setup)
  1. On GitHub go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Ngongotahā add-match" and set an expiry (e.g. 1 year).
  3. Under Repository access choose Only select repositories and pick your data repo only.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Generate, copy the token and paste it above.

The token can only edit that one repo, so even if it leaked it could not touch anything else on your account. You can revoke it any time.
